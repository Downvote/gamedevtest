# Byte-Size Studio

A small game-studio management sim for Roblox. You open a tiny studio in a garage with two developers and a little
money, pick a genre, a topic, a platform, a size and a focus, and watch your crew type away at their desks while
their ideas pop out over their heads. When the build is done you polish out the bugs or ship it, four critics review
it out of 10, and it sells week after week. Hits bring money and fans; money trains the crew, hires more and moves
you into a bigger office; research points unlock new genres and topics; new platforms come out as the years go by;
each year ends with an awards night.

Every studio on a server stands on its own plot along one street. You walk out of your office as a little chibi
founder, the camera following, to visit the other studios and watch their crews at work, and you decorate your plot
in Build mode: trees, benches, lamps, a fountain, an arcade kiosk, a billboard, a food truck.

The loop is a simplified take on the studio-sim genre, with Kairosoft's *Game Dev Story* as the reference for how it
plays. The names, platforms, critics, content, numbers and art are this game's own. The look, the build system and
the formats are Random Bakery's (`Downvote/test`): a cut-away isometric diorama seen through the pixel filter (an
orthographic camera at 45° and 30°, so every floor edge steps exactly two pixels across for one down, toon-shaded on
a palette with 1 px ink outlines), the same pixel font, Rojo with strict Luau, a server that decides everything,
pure Data and Logic modules with specs, and the fake-engine simulator and preview tools.

The whole game is built from code with [Rojo](https://rojo.space): no meshes, decals or uploaded images. Every model
is put together from parts at runtime.

## Layout

```
default.project.json     Rojo project (Shared -> ReplicatedStorage, Server -> ServerScriptService,
                         Client -> StarterPlayer.StarterPlayerScripts; no avatars)
src/shared/              Types, Net, Config, Data (content), Logic (pure rules), Render (pixel maths), Models, Locale
src/server/              Main.server.luau, Services/*
src/client/              Main.client.luau, Controllers/*, Pixel/* (the pixel filter), UI/*
tests/                   run.luau (spec runner), TestKit.luau, Career.luau, specs/*.spec.luau
scripts/check.sh         the check every change has to pass
tools/                   setup.sh, defs/, sim/, preview/
```

## Tools

```sh
sh tools/setup.sh
```

puts Rojo 7.4.4 (as in `rokit.toml`), luau and luau-lsp 1.70.1 in `~/.local/rbx-tools/bin` (or `$TOOLS/bin`).

## Build

```sh
rojo build default.project.json -o build/ByteSizeStudio.rbxlx
```

or `rojo serve default.project.json` and connect with the Rojo Studio plugin. Git ignores `build/`, place files and
`sourcemap.json`.

## Checks

```sh
bash scripts/check.sh
```

Rojo sourcemap, luau-lsp strict analysis of `src` (0 errors), luau-compile (compiler limits luau-lsp cannot see), the
specs (`tests/run.luau`, on a copy of `src/shared` with string requires), the Rojo build. It ends with
`ALL CHECKS PASSED`. To print one career of the Economy spec's player: `luau tests/career.luau -a <seed>` (after the
check has built `build/luautest`).

## Before you publish

1. Game Settings -> Security: turn on **Studio Access to API Services** (DataStores; without it saves live in memory
   only and a warning says so) and **Allow Mesh / Image APIs** (the pixel filter and the pixel font draw with
   `EditableImage`; without it the game runs in the classic 3D look with Press Start 2P text).
2. Places -> Server size: 6 is plenty (each player has their own office on a plot of their own).
3. `Config/Monetization.luau` is empty: this version sells nothing. Badges and sounds stay off while their ids are 0.
4. Give the game a thumbnail and an icon.

## Fonts and licences

Every text is drawn in the pixel font Random Bakery uses: `src/shared/Render/PixelFontData.luau` holds the glyphs as
bit masks, generated by `scripts/gen_pixelfont.py` from the "Minecraft" TTF by Craftron Gaming (copied from Random
Bakery with its generator). The TTF itself is not in this repository and stays out until its licence is confirmed;
only the derived glyph data is. **Before you publish**, check that the font's licence allows use in a monetised
experience, and don't use the "Minecraft" name in the game (it is a Mojang trademark). Press Start 2P, the fallback,
is a Roblox built-in font. The preview tool's fonts (Press Start 2P and Montserrat, OFL) carry their licences in
`tools/preview/fonts`.
